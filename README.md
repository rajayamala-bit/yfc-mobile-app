# YFC (Youth Fellowship Community) Mobile App

> A cross-platform community and fellowship application built with Flutter, Dart, SQLite, and Firebase, featuring real-time communication, automated daily feeds, and notification systems.

## 🌟 Key Highlights & Features

- **Real-Time Communication:** Live chat and fellowship member directory.
- **Daily Automated Feed Sync:** Automated background feeds with HTML rendering support.
- **Offline Data Sync:** Local caching using SQLite for seamless offline accessibility.
- **Smart Notification System:** Integrated Firebase Cloud Messaging (FCM) and exact alarm permissions for scheduled alerts.
- **Clean Architecture:** Built with Flutter & Dart for smooth 60 FPS cross-platform performance.

---

## 🛠️ Tech Stack

- **Frontend & Logic:** Flutter, Dart
- **Local Database:** SQLite
- **Cloud & Messaging:** Firebase Cloud Messaging (FCM)
- **CI/CD Automation:** GitHub Actions (Automated feed workflows)
